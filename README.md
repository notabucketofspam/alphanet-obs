# alphanet-obs

## Introduction

I spent $0.69 (nice) to get Google Gemini Antigravity Orchestrator to convert [my existing alphanet nodejs code](https://github.com/notabucketofspam/alphanet) into an OBS Effects Filter plugin.

## Installation

If you're on Windows, you can put it in:
```
C:\ProgramData\obs-studio\plugins\alphanet-obs\
```

If you're not on Windows, you can put it somewhere else.
